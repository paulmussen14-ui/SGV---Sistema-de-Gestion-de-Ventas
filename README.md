# SGV - Sistema de Gestión de Ventas para Emprendimientos

## Proyecto - Desarrollo de un Software Computacional

**Unidad Didáctica:** Algoritmos para la solución de problemas  
**Evidencia:** AA1 - Proyecto Parte 1: Diseño inicial  
**Lenguaje:** Java  
**Paradigma:** Programación Orientada a Objetos (POO)

---

# 1. Descripción del proyecto

El **Sistema de Gestión de Ventas para Emprendimientos (SGV)** es un software
computacional desarrollado en Java que permitirá procesar ventas de manera
sencilla y automatizada.

El sistema estará orientado principalmente a pequeños emprendimientos que
necesitan realizar cálculos básicos relacionados con sus ventas.

Para la primera versión del proyecto se implementarán algoritmos secuenciales
y estructuras condicionales que permitan registrar los datos de una venta,
calcular el subtotal, aplicar descuentos y determinar el total de la operación.

El proyecto será desarrollado progresivamente durante las diferentes
Actividades de Aprendizaje (AA1, AA2, AA3 y AA4).

---

# 2. Problema identificado

Los pequeños emprendimientos pueden realizar el cálculo de sus ventas
manualmente, lo que puede generar errores en operaciones como:

- Cálculo del subtotal.
- Aplicación de descuentos.
- Cálculo del importe final.
- Determinación de la categoría de una venta.
- Registro de cantidades.

Además, realizar estas operaciones manualmente puede generar pérdida de tiempo
y dificultades para mantener un proceso ordenado.

Por ello, se propone desarrollar un software que permita automatizar el
procesamiento básico de una venta utilizando algoritmos y programación
orientada a objetos.

---

# 3. Justificación

Las ventas representan una actividad importante para cualquier emprendimiento.

La automatización de los cálculos permite reducir errores y mejorar el tiempo
necesario para procesar una operación.

El desarrollo de este proyecto permitirá aplicar conceptos fundamentales de
programación, entre ellos:

- Algoritmos.
- Variables.
- Identificadores.
- Tipos de datos.
- Operadores.
- Entrada de datos.
- Procesamiento de datos.
- Salida de datos.
- Algoritmos secuenciales.
- Estructuras condicionales.
- Pseudocódigo.
- Diagramas de flujo.
- Programación Orientada a Objetos.
- Lenguaje Java.

---

# 4. Objetivo general

Desarrollar un software computacional en Java que permita procesar una venta
de un emprendimiento mediante algoritmos secuenciales y condicionales,
aplicando conceptos de programación orientada a objetos.

---

# 5. Objetivos específicos

1. Identificar los datos necesarios para procesar una venta.

2. Definir las variables utilizadas por el sistema.

3. Identificar los tipos de datos correspondientes a cada variable.

4. Diseñar algoritmos para el procesamiento de una venta.

5. Implementar algoritmos secuenciales utilizando Java.

6. Implementar estructuras condicionales simples, dobles y múltiples.

7. Calcular automáticamente el subtotal de una venta.

8. Aplicar descuentos de acuerdo con el importe de la venta.

9. Calcular automáticamente el total de la operación.

10. Clasificar la venta según su importe.

11. Diseñar el código utilizando conceptos básicos de programación orientada
    a objetos.

# 8. Requerimientos del sistema

## 8.1 Requerimientos funcionales

El sistema deberá permitir:

- RF01: Registrar el nombre del cliente.
- RF02: Registrar el nombre del producto.
- RF03: Registrar el precio unitario del producto.
- RF04: Registrar la cantidad de productos.
- RF05: Calcular el subtotal de la venta.
- RF06: Aplicar un descuento según el subtotal.
- RF07: Calcular el total de la venta.
- RF08: Clasificar la venta según su importe.
- RF09: Mostrar los datos de la venta.
- RF10: Mostrar un resumen final de la operación.

## 8.2 Requerimientos no funcionales

- RNF01: El sistema será desarrollado utilizando Java.
- RNF02: Se utilizará Programación Orientada a Objetos.
- RNF03: El código deberá ser organizado y legible.
- RNF04: Los nombres de variables y métodos deberán ser descriptivos.
- RNF05: El sistema deberá ejecutarse mediante consola.
- RNF06: El sistema deberá realizar cálculos automáticamente.
- RNF07: El sistema deberá evitar errores básicos mediante validaciones.
